# Collapse Code

Be aggressive and destructive within the requested scope. Preserve only the
required capabilities.

Delete obsolete code. Collapse weak state, transformations, interfaces,
abstractions, ownership, and control flow. Re-audit after each repair because
one collapse may expose another.

Finish only when a fresh subagent, given the target without prior conclusions,
finds no further material compression. Repair material findings and repeat with
a fresh subagent.
